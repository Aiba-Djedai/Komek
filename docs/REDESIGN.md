# Kömek: новая структура и дизайн

Версия находится в `feat/platform-improvements-v2`. Предыдущие версии остаются в `feat/platform-improvements` и `feat/volunteer-platform-mvp`.

## Принципы

- Основной текст — 16–18 px, вспомогательные подписи — от 14 px. Контрастный текст, отчётливый фокус и крупные кнопки.
- Одна основная задача на странице. Регистрация, заявка, создание проекта и рассмотрение отклика больше не помещаются в модальные окна.
- На главной — краткое знакомство или обзор. Полный каталог, длинные списки и подробности открываются отдельно.
- У авторизованных пользователей постоянное меню с понятной ролью и разделами. На телефоне оно открывается кнопкой меню; поддерживаются Escape и клавиатурный фокус.
- У страниц собственные URL. Можно поделиться проектом, обновить страницу, вернуться назад или открыть нужную заявку по прямой ссылке. Старый `/dashboard` перенаправляет в соответствующий раздел.

## Страницы

| Адрес                         | Назначение                                                   |
| ----------------------------- | ------------------------------------------------------------ |
| `/`                           | Краткая главная гостя или персональный обзор роли            |
| `/projects`                   | Каталог, поиск, фильтры, сортировка, страницы результатов    |
| `/events/:id`                 | Описание проекта, даты, требования и переход к заявке        |
| `/register?role=volunteer`    | Регистрация волонтёра                                        |
| `/register?role=organization` | Регистрация организации                                      |
| `/login`                      | Вход и раскрывающийся демо-доступ                            |
| `/events/:id/apply`           | Отдельная форма заявки волонтёра                             |
| `/applications`               | Заявки волонтёра, фильтры статусов и пагинация               |
| `/applications/:id`           | Статус, история и подтверждение участия                      |
| `/favorites`                  | Избранные проекты волонтёра                                  |
| `/my-events`                  | Свои проекты организации, фильтры и пагинация                |
| `/my-events/:id`              | Управление проектом, открытие/закрытие набора                |
| `/events/new`                 | Полная форма нового проекта                                  |
| `/my-events/:id/edit`         | Редактирование своего проекта                                |
| `/requests`                   | Список заявок организации, фильтры и пагинация               |
| `/requests/:id`               | Рассмотрение одной заявки и журнал ручного сообщения         |
| `/roster`                     | Подтверждённый состав, отдельный список неподтвердивших, CSV |
| `/reports`                    | Статистика сроков ответов организации                        |
| `/profile`                    | Редактирование профиля                                       |
| `/notifications`              | Уведомления и отметка прочтения                              |
| `/organizations`, `/about`    | Организации и краткий сценарий работы для каждой роли        |
| `/privacy`, `/terms`          | Конфиденциальность и условия                                 |

## Логика данных

API и схема SQLite сохранены. Сохраняются прежние ограничения: роль и владелец, обязательное согласие, запрет дублей, дедлайн перед событием, контроль вместимости, уведомление при решении, отдельное подтверждение участия и состав только из Confirmed. Внешние Telegram/email остаются ручными; интерфейс этого не маскирует.

## Референсы

Пользователь указал volunteers05.kz, ashyqjurek.kz и volunteer.gov. Прямые запросы к ним из рабочей среды вернули `403 Forbidden`, поэтому их текущие страницы и точное оформление не удалось проверить. Реализован самостоятельный дизайн Kömek с каталогом возможностей, крупной типографикой и отдельными рабочими разделами.

## Проверка и развёртывание

`npm test` проверяет API; `npm run test:e2e` — сценарии страниц, роли, данные, мобильное меню, пагинацию и автоматические проверки доступности/контраста axe-core. Эти проверки не заменяют полный ручной аудит доступности.

`render.yaml` в этой ветке описывает отдельный Free-сервис `komek-redesign-demo`, связанный с `feat/platform-improvements-v2`. Сохранение файла и push не означают выполненное развёртывание. Для публикации выберите эту ветку в новом Render Blueprint. Предыдущие сервисы сами на неё не переключаются. На Free SQLite остаётся временной, как и в предыдущей демонстрации.
